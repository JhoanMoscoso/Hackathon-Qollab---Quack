INTEGRATION NOTES
- Use source sheet at 1x; for game display use nearest-neighbor scaling.
- Canvas target is 640x384; tile grid is 20x12, tile size 16px, rendered at 2x.
- Alice accent #4ADBE6; Bob #F5A742.
- State 0 #5BBF6A; state 1 #D64550; superposition #A66CFF plus horizontal stripes.
- Keep shape/pattern cues as well as color; never encode state using color alone.
- This is a first-pass hand-authored base sheet. Review individual tiles in game before final lock.
